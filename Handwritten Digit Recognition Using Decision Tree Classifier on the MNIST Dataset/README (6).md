# MNIST Digit Recognition

A machine learning project that classifies handwritten digits (0–9) using a Decision Tree Classifier.

## Dataset
- MNIST: 70,000 images
- 784 pixel features per image
- 10 digit classes (0–9)

## Method
1. Load and visualize the MNIST dataset.
2. Normalize pixel values to the range 0–1.
3. Split data into 80% training and 20% testing sets.
4. Train a Decision Tree using entropy.
5. Evaluate predictions using accuracy.

## Result
Test accuracy: approximately 88.02%.

## Tools
Python, NumPy, Matplotlib, Scikit-learn, Google Colab.
